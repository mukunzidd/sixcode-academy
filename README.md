# SixCode Academy

SixCode Academy is a mentor-led program for 30–50 developer trainees.

## Program shape

- Core: 12 weeks
- Specialization: 8 weeks
- Team product: 4 weeks
- Mentor ratio: 1 mentor to 5 learners
- Team size: 5 learners
- Sprint length: 1 week
- Daily and weekly check-ins
- Learner-owned progress tracking

The core covers web and workstation basics, UI and UX foundations, JavaScript, systems and data, and working with others. Learners then choose Full-Stack JavaScript and TypeScript, Ruby and Rails, or Mobile with React Native and TypeScript.

Every track ends with a personal capstone and a four-week team product. Teams choose the problem, design the flow in Figma, write the technical documents, and build the product. Mentors who are SixCode engineers help the team shape scope, make technical decisions, and review the work.

Every project submission includes the required gist or repository, README or technical note, test evidence, and learner self-review.

## Communication

All cohort communication happens in SixCode.africa channels created by mentors and their learner groups. Daily check-ins, weekly sprint planning, review questions, decisions, demos, and handoffs stay in those channels.

## AI rules

AI can help with exploration and drafting when the learner records the prompt, reviews every line kept, tests the result, and discloses the assistance. Learners do not submit generated work they cannot explain live.

## SixCode Africa customization points

Before launch, replace the placeholder program data with:

- Local project briefs and partner problems
- Cohort calendar and timezone rules
- Channel naming and moderation rules
- Mentor review windows
- Android and low-bandwidth support guidance
- Local employer, freelance, and startup context
- Completion, certificate, sponsorship, and payment rules

## Run locally

```bash
npm install
npm run dev
```

The local app runs on port 8011 so it can be compared with the existing site on port 8010.
